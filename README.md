# FlashAnki

Jogo de flashcards inspirado no AnkiWeb, com repetição espaçada e gamificação. Roda 100% no navegador, sem dependências.

## Como usar

Abra `index.html` no navegador (ou publique a pasta no GitHub Pages). Os dados ficam salvos no `localStorage`.

## Recursos

- **Baralhos** com contadores Novos / Aprender / Revisar, como no AnkiWeb
- **Estudo** com os botões Errei / Difícil / Bom / Fácil mostrando o próximo intervalo
- **Agendador estilo Anki (SM-2)**: etapas de aprendizado (1 min, 10 min), intervalo de graduação, fator de facilidade, reaprendizado após lapsos e limites diários (20 novos / 200 revisões)
- **Adicionar, editar, navegar e pesquisar** cartões, com opção de cartão invertido
- **Importar/Exportar**: backup em JSON ou importação de texto `frente;verso` (ou separado por TAB)
- **Gamificação**: XP, níveis, combos, sequência de dias e conquistas
- **Estatísticas**: revisões do dia, acertos, cartões jovens/maduros e gráfico dos últimos 30 dias

## Atalhos

| Tecla | Ação |
|---|---|
| Espaço / Enter | Mostrar resposta (depois: Bom) |
| 1 · 2 · 3 · 4 | Errei · Difícil · Bom · Fácil |
| Ctrl+Z | Desfazer última resposta |
| Ctrl+Enter | Salvar cartão no editor |
